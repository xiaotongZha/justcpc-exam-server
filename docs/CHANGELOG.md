# 更新记录

## 1.0.1 · 2026-10-20

- Linux 安装、更新、卸载改为每个项目独立的 Shell 脚本，删除通用 Go 安装工具；README 提供 mkdir/curl/执行安装的完整命令。
- 安装下载最新正式版，发行包附带更新和卸载脚本；更新确认后原地替换，保留配置与数据，卸载可选择是否清理数据。
- Windows 保持图形化程序，不附带 Linux 脚本。开发资料、配置模板和构建产物分别归入 docs、config、build；项目名称保持完整。

## 1.0.0 · 2026-10-19

- 重整考生与监考页面，突出导入考试包、导出提交包、试题下载和提前交卷。
- 提交成功确认后返回题目总览；每人每题仅保留最后一份代码，跨语言提交也会替换。提前交卷后禁止再次登录，修复主动交卷后的登录失效误报。
- 考生管理、提交记录和操作记录支持服务端分页；时间设置支持直接输入与快捷时长；考生须知统一文案并突出纪律警告。
- 导出提交包在点击“知道了”后才触发下载；试题下载前后端限制 5 秒内重复请求。
- Windows 提供单实例启动窗口、管理页入口及停止操作；Windows 启动窗口和 Linux 终端显示当前试题解压密码与配置说明。
- 发行包仅含程序、可预先编辑的 config.json 和使用说明；空密钥 / 初始密码首次启动自动生成并保存，已有配置与管理员密码保留。

升级：停止服务，保留 data/ 和 config.json，仅替换程序。Windows 原生窗口已交叉编译，尚未实机验证。
